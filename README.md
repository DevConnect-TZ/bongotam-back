# BongoTam Backend

Laravel 11 API backend for the BongoTam video streaming platform.

## Features
- Mobilipa and SonicPesa mobile payment integrations
- Runtime payment gateway switching without server restarts
- Wakubwa Zone VIP subscription system with admin management
- Seeded test videos with 400 TZS pricing for Mobilipa verification

## Testing
```bash
php artisan test
```
